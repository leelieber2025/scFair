# Examples

Usage is on Read the Docs:

- [Quickstart](https://scfair.readthedocs.io/en/latest/quickstart.html)
- [Tutorials](https://scfair.readthedocs.io/en/latest/tutorials/index.html)

Benchmark and research scripts live in `bak/examples/` (local archive, not
on GitHub or PyPI). They depend on local datasets under `examples/data/`
and are not required to install or run scFair.
